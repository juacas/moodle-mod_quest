Despliegue

Instala Questournament en Moodle.

Esta guía describe v2.0.0, incluida la composición de desafíos con varias preguntas, la corrección mixta y la planificación. Comprueba que la descarga elegida contiene esta versión.

Tres formas de instalación

Elige cómo instalarlo.

Comprueba que el version.php del paquete declara v2.0.0 y es compatible con tu sitio Moodle antes de actualizar.

1. Marketplace de Moodle

Busca QUESTOURnament para tu versión de Moodle y descarga su ZIP. En Moodle, entra en Administración del sitio → Plugins → Instalar plugins y sube el ZIP. El botón del Marketplace en Moodle conduce a la descarga; no instala directamente.

Abrir Moodle Marketplace →

2. ZIP de GitHub Releases

Abre la sección Releases del proyecto y descarga el ZIP de la versión publicada. Súbelo con el instalador de Moodle o descomprímelo en el directorio mod/quest del servidor.

Abrir GitHub Releases →

3. Git clone y pull

Desde el directorio mod/ de Moodle, clona el repositorio como quest: git clone https://github.com/juacas/moodle-mod_quest.git quest. Para actualizar, ejecuta git pull --ff-only dentro de mod/quest.

Abrir repositorio →
Después de cualquiera de las tres vías: haz una copia del sitio, entra en Administración del sitio → Notificaciones para ejecutar la actualización de la base de datos y prueba creación, acceso al banco y copia/restauración en un curso de pruebas.
Antes del despliegue

Haz una prueba pequeña.

Crea un desafío abierto, uno completamente autocorregible y otro con ensayo. Comprueba permisos, ponderación de notas, visibilidad del feedback, calendario y una restauración de prueba.

Lista rápida

  • Confirma la compatibilidad de Moodle y PHP indicada para el plugin.
  • Usa el nombre de carpeta quest.
  • Ejecuta la actualización de base de datos como administrador.
  • Revisa permisos y acceso al banco.
  • Restaura una copia en un curso de pruebas.

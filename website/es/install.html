Desde Moodle

Abre Administración del sitio → Plugins → Instalar plugins, busca Questournament y sigue el instalador.

Descarga una versión

Descarga el paquete del directorio de plugins y coloca el módulo en la carpeta /mod de Moodle.

Ver versiones →
⌘

Clona el código

Para desarrollo, clona el repositorio en mod/quest y deja que Moodle complete la actualización.

Después de copiar los archivos

Deja que Moodle termine el relevo.

Entra como administrador y visita la página de notificaciones. Moodle detectará el módulo y ofrecerá la actualización de la base de datos.

Administración Moodle
1. Coloca Questournament en /mod/quest
2. Visita Administración del sitio → Notificaciones
3. Confirma la actualización
4. Añade Questournament a un curso

Checklist inicial

  • Comprueba la versión de Moodle compatible.
  • Mantén el nombre de carpeta quest.
  • Ejecuta la actualización como administrador.
  • Prueba un reto pequeño antes de abrirlo a todo el grupo.

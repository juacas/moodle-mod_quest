Deployment

Install Questournament in Moodle.

This guide describes v2.0.0, including multi-question challenge composition, mixed grading and scheduling. Check that the selected download actually contains this version.

Three installation routes

Choose how to install it.

Check that the package's version.php declares v2.0.0 and is compatible with your Moodle site before upgrading.

1. Moodle Marketplace

Find QUESTOURnament for your Moodle version and download its ZIP. In Moodle, open Site administration → Plugins → Install plugins and upload the ZIP. The Marketplace button in Moodle leads to the download; it does not install directly.

Open Moodle Marketplace →

2. GitHub Releases ZIP

Open the project's Releases page and download the ZIP for the published release. Upload it through Moodle's plugin installer, or extract it into the mod/quest directory on your server.

Open GitHub Releases →

3. Git clone and pull

From Moodle's mod/ directory, clone the repository as quest: git clone https://github.com/juacas/moodle-mod_quest.git quest. To update, run git pull --ff-only inside mod/quest.

Open repository →
After any route: back up the site, visit Site administration → Notifications to run the database upgrade, then test challenge creation, question-bank access and backup/restore on a test course.
Before a full launch

Run a small pilot.

Create one plain challenge, one fully automatic challenge and one challenge containing an essay. Check teacher and student permissions, mark weighting, feedback visibility, scheduling and a test restore.

Quick checklist

  • Confirm the plugin's Moodle and PHP compatibility.
  • Use the plugin folder name quest.
  • Run the database upgrade as an administrator.
  • Check question-bank access and capabilities.
  • Restore a backup in a test course.

Deployment · 03

Install the activity. Start the story.

Choose the path that fits your Moodle setup: install from the official directory, download a release or work from the open-source repository.

◎

From Moodle

Open Site administration → Plugins → Install plugins, search for Questournament and follow Moodle’s installer.

Open directory →
↓

Download a release

Download the package from the Moodle plugins directory and place the module in your Moodle /mod folder.

View releases →
⌘

Clone the source

For development, clone the repository into mod/quest, then let Moodle complete the database upgrade.

Open GitHub →
After the files are in place

Let Moodle finish the handoff.

Sign in as an administrator and visit the notifications page. Moodle detects the module, checks requirements and offers the database upgrade.

Moodle admin
1. Place Questournament in /mod/quest
2. Visit Site administration → Notifications
3. Confirm the database upgrade
4. Add Questournament to a course

First-run checklist

  • Confirm your Moodle version is supported by the release.
  • Keep the plugin folder named quest.
  • Run the upgrade as an administrator.
  • Create a small pilot quest before a full cohort launch.

Deployment

Install Questournament in Moodle.

This guide describes the current Questournament release, including multi-question challenge composition, mixed grading and scheduling.

Get the plugin

Check the current release requirements and download the package. Install it through Site administration → Plugins → Install plugins.

Moodle plugins directory →

Explore its features

Compose challenges with several questions, combine automatic and manual grading, and organize dates on the timeline. This release guide covers all of these features.

Usage guide →

Upgrade safely

Back up your site, place the plugin in mod/quest, then visit Site administration → Notifications as an administrator. Test challenge creation, question-bank access and backup/restore before using it with a class.

Creation guide →
Before a full launch

Run a small pilot.

Create one plain challenge, one fully automatic challenge and one challenge containing an essay. Check teacher and student permissions, mark weighting, feedback visibility, scheduling and a test restore.

Quick checklist

  • Confirm the plugin's Moodle and PHP compatibility.
  • Use the plugin folder name quest.
  • Run the database upgrade as an administrator.
  • Check question-bank access and capabilities.
  • Restore a backup in a test course.
